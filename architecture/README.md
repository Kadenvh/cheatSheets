# architecture/

The consolidated long-term store of this project's document lifecycle (see `exploration/README.md` for the full lifecycle).

What lives here: completed implementations' design records, superseded-but-load-bearing strategy documents with extraction receipts, and curated architectural truth that future sessions and agents treat as ground.

Rules:

- Nothing arrives here unfinished. Work consolidates into `architecture/` only after its loop has closed with a verification artifact.
- Every document that gets retired into here carries a receipt: what was extracted, where it went, why it was superseded.
- This directory is the human-auditable prototype of Cortex's long-term memory store.
